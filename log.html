                                                    # 更新日志

                                                    # v.0.3.81 （ #2026-10-12 ）

                                                    • 属性名转换结果缓存，表格与列属性透传不再在每次 render 中重复执行正则；jsdom 基准中，虚拟滚动 30 列切换窗口时组件自身的 render 耗时约降低 60%。
                                                    • 合并单元格改为按连续相同值分段计算，每个单元格只读取一次响应式字段，并共享不变的合并结果数组。
                                                    • 对象形式的 columns 列 key 保持稳定，修改列属性不再重建全部列。
                                                    • 多级表头隐藏子列后，仅在子列显隐变化时重建该组列；其他列属性变化不再连带重建。
                                                    • 文档：补充透传属性列表、全局 page/menu 开启规则、虚拟模式下排序与选择的行为说明，以及性能建议。

                                                    # v.0.3.80 （ #2026-09-25 ）

                                                    • attach 仅同步实际变化的配置值；父级重渲染传入相同数据数组时，不再重复刷新虚拟表格。

                                                    # v.0.3.79 （ #2026-09-25 ）

                                                    • 虚拟滚动按帧合并、缓冲窗口复用，移除滚动过程中的无条件重排和全量响应式遍历。
                                                    • 选择状态使用 Set，补齐滚动、resize、keep-alive 和动态模式切换的资源清理。
                                                    • 修复请求竞态、同步/异步异常 loading 和销毁后的回填。
                                                    • 普通表格减少重排，列数组累积和长段合并避免重复复制及递归溢栈。
                                                    • 保持原有 API 和 Element UI 样式；新增真实模板、10 万行滚动及新旧 DOM/CSS 回归测试。
